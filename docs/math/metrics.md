# Метрики вкладки «Метрики» и скринера

Код: [`metrics.js`](../../api/_dossier/math/metrics.js) (досье одной компании, сборка
`computeMetrics`), [`market.js`](../../api/_dossier/math/market.js) (таблица скринера, недельная
корреляция). Те же формулы лежат в подсказках интерфейса (поле `formula` каждой метрики).

Правила для всех чисел:

- считаются только по **завершённым** сессиям; бегущая сессия не считается дневной доходностью;
- ниже заявленного минимума наблюдений значение `null`, интерфейс показывает «нет данных»,
  ничего не подставляется;
- `YEAR = 252` сессии для годовых пересчётов; «год» это последние 252 сессии;
- безрисковая ставка принята за 0 (написано в подсказке каждой метрики, где это важно);
- цена без дивидендов (Yahoo, дневные свечи), поэтому доходности ниже полной доходности акционера;
- метрики описывают прошлое и не предсказывают будущее.

Обозначения: `R` простая дневная доходность `C_t/C_{t-1} − 1`, `r` лог-доходность, `M` доходность
домашнего бенчмарка того же дня, `n` число наблюдений.

## 1. Доходность

Календарные доходности `R = C_t / C_base − 1`, где `C_base` последнее закрытие на календарную дату
или раньше (1 д, 1 н, 1 м, 3 м, 6 м, с начала года, 1 г). `CAGR = (C_T/C_0)^{1/лет} − 1` при истории
не короче полугода. Импульс 12−1: `C_{−1 мес} / C_{−12 мес} − 1`.

## 2. Риск

- Волатильность `σ = sd(r)·√252` по 20, 60, 252 сессиям и всей выборке (минимумы 20/60/60/252).
- Отклонение вниз `σ_d = √(mean(min(R,0)²))·√252`, вверх аналогично, полудисперсия, доля падений
  в дисперсии (минимум 60).
- Просадка `D_t = C_t / max_{s≤t} C_s − 1`; максимальная, текущая, средняя, самая долгая и текущая
  длительность в сессиях. Индекс Ulcer `UI = √(mean(D²))` в процентах (годовое окно, минимум 20).
- Самая длинная серия падений (минимум 20).

## 3. Риск и доходность

Все на 252 сессиях, минимум 60 (если иное не указано), `rf = 0`:

| Метрика | Формула |
|---|---|
| Шарп | `SR = mean(R)/sd(R)·√252` |
| ошибка Шарпа (Lo, 2002) | `SE = √((1 + SR²/504)/n)·√252`, независимые доходности; ±2·SE примерный 95 % интервал |
| Сортино | `mean(R)/σ_d·√252` |
| Кальмар | `CAGR₁у / |макс. просадка|` в годовом окне (не классические 3 года), минимум 126 |
| Мартин (UPI) | `CAGR₁у / UI`, минимум 126 |
| Омега (порог 0) | `Σmax(R,0) / Σmax(−R,0)` |
| прибыль к боли | `ΣR / Σmax(−R,0)` |
| информационный | `mean(R−M)/sd(R−M)·√252`, минимум 60 пар |
| Трейнор | `252·mean(R)/β`, `null` при `β < 0.1` |
| M² | `SR·σ_M`, и сверх бенчмарка `M² − 252·mean(M)` |

Шарп на одном годе даёт ошибку порядка 1 (при `SR ≈ 1` интервал примерно от 0 до 2): различия
между компаниями в десятые доли шума.

## 4. Связь с рынком

Регрессия `R = a + b·M` по МНК на парах того же дня за 252 сессии (минимум 60): бета `b`, скорректированная
бета Блюма `⅔·b + ⅓`, бета за 60 сессий, альфа (годовая), t-статистики, `R²`, корреляция, ошибка
слежения `sd(R−M)`, идиосинкразическая волатильность (остаток), захват роста и падения (отношение
средних на днях роста / падения рынка, минимум 20 дней), бета вверх / вниз (разные склоны на днях
роста и падения), доля дней лучше бенчмарка.

## 5. Распределение и зависимость

Асимметрия, эксцесс, Харке-Бера `JB = n/6·(S² + K²/4)` (минимум 100; p по `χ²₂`), доля дней роста,
лучший и худший день, `средний рост / средний убыток`, хвостовое отношение `|q95| / |q05|`
(квантили простых доходностей, минимум 60), автокорреляция на лагах 1 и 5, Люнг-Бокс `Q(10)` для
доходностей и квадратов доходностей (кластеризация волатильности), показатель Хёрста (DFA первого порядка,
минимум 200), отношение дисперсий Ло-Маккинли `VR(5)` с робастным к гетероскедастичности z (минимум 120).

Показатель Хёрста и `VR` на малых выборках шумят: «нет данных» ниже минимумов честнее, чем оценка.

## 6. Волатильность по диапазону

Дневные дисперсии по барам (последние 60, нужно ≥ 20 корректных баров и ≥ 80 % окна), годовые в процентах:

$$
\text{Parkinson: } \tfrac{1}{4\ln 2}\overline{\ln^2(H/L)},\quad
\text{Garman–Klass: } \overline{\tfrac12\ln^2(H/L) - (2\ln 2 - 1)\ln^2(C/O)}
$$

Роджерс-Сатчелл `mean(ln(H/C)·ln(H/O) + ln(L/C)·ln(L/O))`; Янг-Чжан
`σ²_ночь + k·σ²_сессия + (1−k)·σ²_RS`, `k = 0.34 / (1.34 + (n+1)/(n−1))`; доля ночной дисперсии.
ATR(14) по Уайлдеру, ATR в процентах цены, средний дневной диапазон за 20 баров. Оценки по диапазону
предполагают отсутствие разрывов внутри сессии и малый дрейф: у акций с большими гэпами Паркинсон
и Гарман-Класс занижают волатильность (поэтому рядом Янг-Чжан и сравнение с close-to-close).

## 7. Тренд и импульс

Расстояние до SMA 20/50/200, разрыв SMA50/SMA200, RSI(14) по Уайлдеру, MACD(12, 26, 9).
Это описательные индикаторы; доказательств прогностической силы здесь не проверяется.

## 8. Новостной поток (последние 30 дней переданных заголовков)

Число сюжетов за 24 часа, 7 и 30 дней (нижняя граница: что нашёл поиск); ускорение
`(сюжеты 7 дней / 7) / (сюжеты прошлых 23 дней / 23)` (минимум 5 в базе); средний тон (−1…1, без
отчётов, минимум 3), изменение тона, разброс, доли позитивных и негативных (минимум 5);
разнообразие источников: число, энтропия Шеннона `−Σ p log₂ p`, равномерность `H / log₂ k`,
концентрация `HHI = Σ p²` (минимум 5 сюжетов); число языков, сюжеты по типам, доля официальных отчётов.
Тон и тип получены автоматическим классификатором и ошибаются.

## 9. Скринер (`market.js`)

Строка на компанию: тот же набор доходностей, годовая волатильность, бета, просадка, RSI, расстояние
до SMA, до 52-недельного максимума; спарклайн из ≤ 60 закрытий, приведённых к 100. Минимум 60
доходностей для статистик. Данные старше 10 дней считаются устаревшими и помечаются.

Корреляция: **недельные** лог-доходности (неделя с воскресенья; недельный возврат между двумя
последними закрытиями соседних недель; неделя без сессий рвёт цепочку; бегущая неделя не входит),
попарно-полная корреляция Пирсона, `null` ниже 26 общих недель. Недельный шаг снимает асинхронность
часов торгов Азии, Европы и США (дневные корреляции между рынками занижены). Медианы по регионам.

## 10. Ограничения

Простые доходности без дивидендов; безрисковая ставка 0; годовые числа по одному году истории;
оценки не имеют доверительных интервалов (кроме ошибки Шарпа); классические коэффициенты предполагают
независимые доходности, а реальные ряды имеют кластеры волатильности и тяжёлые хвосты.
