# Экономические последствия события

Код: `api/_dossier/math/consequences.js`. Интерфейс: `src/dossier/consequences.ts`.

У каждого события в ответах `/api/dossier` (досье компании, `view=wire`, `view=world`, включая `more`, и заголовки `view=economy`) есть поле `consequences`. Оно собирается по фиксированным правилам из уже посчитанных величин и таблицы типичных каналов. Языковые модели не используются, новых чисел модуль не оценивает, цен не обещает. Тексты по умолчанию русские, `?cl=en` даёт английские.

## Состав поля

| Часть | Что в ней | Откуда |
|---|---|---|
| `summary` | одна фраза: тип, наблюдаемое, ожидание, надёжность | сборка из частей ниже |
| `direction` | `up`, `down`, `uncertain` или `insufficient` и пояснение | коридор 80% на 5 сессий |
| `observed` | CAR, z, p, q, объём, движение до публикации; для мира — движения рынков | `quant.js`, `math/report.js`, `world.js`, `economy.js` |
| `magnitude` | центр, коридор 80%, доля роста, число аналогов на 1, 5 и 20 сессий | `math/forecast.js`, `computeOutlooks` |
| `horizon` | типичный горизонт для вида события | таблица в модуле (суждение) |
| `evidence` | балл значимости и подтверждение источниками | `math/significance.js`, `world.js` |
| `channels` | выручка, издержки, риски, оценка и финансирование | таблица в модуле (суждение) |
| `exposed` | компания, другие компании, индекс, валюта, сырьё, доходности | измеренная связь, где есть; иначе типичный канал с пометкой |
| `confidence` | `low`, `medium`, `high` и причины | правила ниже |
| `watch` | что подтвердит или опровергнет | таблица в модуле |
| `caveat` | не причинность и не инвестиционная рекомендация | постоянный текст |

Каналы, горизонты и списки «что отслеживать» заданы суждением по виду события. Это не измеренные факты, и интерфейс так их и подписывает.

## Правила

**Наблюдаемая реакция** (дни 0 и +1, модель рынка):

- «отличима от обычных колебаний», если |z| ≥ 1,96 и q ≤ 0,1 (поправка Бенджамини — Хохберга);
- «велика сама по себе», если |z| ≥ 1,96, а q больше 0,1 или не рассчитано;
- «заметная, но неубедительная», если 1 ≤ |z| < 1,96;
- «в пределах обычных колебаний», если |z| < 1.

Если перед публикацией |preZ| ≥ 1,96, об этом сказано отдельно: связь с сообщением под вопросом.

**Ожидание и направление.** Оценка по аналогам та же, что на вкладке прогноза (`docs/math/forecast.md`), но считается для всех показанных классифицированных событий, а не только для 15 последних. Если аналогов меньше порога (`rule = baseline`), центр и доля роста не показываются («нет данных»), а коридор подписан как обычная волатильность акции. Направление `up` или `down` ставится только когда коридор 80% на 5 сессий целиком по одну сторону нуля. Обычно он включает ноль, и направление «не определено».

**Надёжность** — это достаточность данных, а не вероятность направления. По баллу за каждое условие:

1. официальный документ SEC или не меньше трёх изданий;
2. реакция отличима от шума;
3. эффективное число аналогов на 5 сессий не меньше 8.

3 балла — высокая, 2 — средняя, иначе низкая. Для мировых событий не выше средней (средняя: независимых источников не меньше 2,5 и есть измеренные движения рынков). Для заголовков экономического блока всегда низкая.

## Чего нет

- В ленте компаний (`view=wire`) аналоги и значимость не считаются, событийный анализ есть только для смен руководства. Остальное — «нет данных»; полный расчёт есть в досье компании.
- Для событий без компании ожидаемый масштаб и интервал не рассчитываются.
- Для сообщений типа «прочее» аналоги не подбираются.
- Движения рынков совпадают с событием по времени. Причинность не проверяется.
