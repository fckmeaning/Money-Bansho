# Money Bansho: ознакомление для следующего Claude

Прочитай этот файл целиком перед работой. Отвечай пользователю по-русски, коротко. Дата последней передачи: 27.11.2026, поздний вечер; сроки хакатона очень жёсткие.

## Что это

Финансово-геополитический дашборд: как акции компаний двигаются на фоне экономики, политики и внутренних событий (смена CEO и ключевых людей), репутация компании, свежие новости, математические модели поверх этого. Особый упор на источники Китая, Европы, Израиля и о КНДР.

Основа: [World Monitor](https://github.com/koala73/worldmonitor), коммит `7d5083c4`, Copyright (C) 2026 Elie Habib, **AGPL-3.0**.

## Решения пользователя (не переспрашивать)

- Главное на демо: **досье компании** (`/dossier.html`), около 50 компаний мира.
- Только бесплатные источники без ключей.
- Стиль: тёмный терминал, статичный и солидный. Без градиентов, свечений, пульсаций, эмодзи, значков «AI», «beta», «new», промоблоков. Интерфейс не должен «меняться сам» и показывать зелёное оформление (зелёный только для роста цены).
- Дизайн очень важен: качественное меню, панели-плашки, много графиков, таблиц и разных метрик, понятное оформление событий и процессов.
- Математика «неимоверно важна»: своя, сложная, с формулами и объяснениями, но честная (без выдуманных данных и обещаний цены).
- Из World Monitor можно копировать код частями или целиком (пользователь говорит, что разрешение есть; лицензию всё равно не менять). Источников нужно больше.
- Не читать весь проект: копировать и читать только нужное.
- **Токены расходуются быстро:** не запускать много агентов разом (2–3 максимум), доводить часть до конца, коммитить и пушить.
- Нужна публичная ссылка для жюри (деплой позже, `DEPLOY.md` пригодится).
- Пуш прямо в `main`.

## Обязательные правила

- `LICENSE` (AGPL-3.0), копирайты и пометку «Based on World Monitor» со ссылкой сохранять.
- Бренд и логотип World Monitor не использовать. Идентификаторы кода (proto, пути `server/worldmonitor`, заголовки, переменные окружения, ключи localStorage) **не переименовывать**.
- Данные не выдумывать: при сбое показывать «нет данных».
- Не коммитить секреты. Отключение защит (в том числе ограничения частоты запросов) только после явного согласия пользователя.
- `AGENTS.md`, `ARCHITECTURE.md`, большая часть `docs/` остались от оригинала и описывают upstream.

## Запуск и проверки

```bash
npm install                 # Node 24 (.nvmrc)
npm run dev                 # http://localhost:3000/dossier.html и /dashboard
node node_modules/@typescript/native/bin/tsc --noEmit
node --test "api/_dossier/**/*.test.mjs"
npm run lint:api-contract   # новые файлы в api/ добавлять в api/api-route-exceptions.json
npm run build:deploy        # сборка для Vercel, см. DEPLOY.md
```

Первый старт Vite занимает 20–60 секунд.

## Известные ограничения

- Новости обновляются опросом (досье 20 с, лента 30 с), не посекундно. Жюри этого не обещать.
- Анализ по ключевым словам: заголовок с именем без должности может не распознаться как смена руководства; чужие назначения иногда приписываются упомянутой компании.
- Лента Google News ограничена по объёму и тяготеет к свежему, поэтому «всплеск новостей» может быть завышен. Иногда отвечает 429; условия разрешают только личное некоммерческое использование.
- Официальных лент КНДР найти не удалось.
- Часть тестов оригинала (бренд, `vercel.json`, удалённые README) ожидаемо падает. CI и git-хуки оригинала не перенесены.
