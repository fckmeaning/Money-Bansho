# Динамика: бета во времени, режимы, точки перелома

Код: [`kalman.js`](../../api/_dossier/math/kalman.js), [`hmm.js`](../../api/_dossier/math/hmm.js),
[`changepoint.js`](../../api/_dossier/math/changepoint.js), оптимизатор
[`optimize.js`](../../api/_dossier/math/optimize.js) (Нелдер-Мид), сборка в `report.js`. Тесты:

    node --test api/_dossier/math/kalman.test.mjs api/_dossier/math/hmm.test.mjs api/_dossier/math/changepoint.test.mjs

Вход везде: дневные логарифмические доходности, старые вначале, все числа конечные (иначе `null`).
Это описание прошлого поведения цены, а не прогноз и не совет.

| Модель | Минимум наблюдений |
|---|---|
| Калман (бета) | 60 пар (акция, бенчмарк) того же дня |
| HMM (режимы) | 100 |
| Точки перелома | 60 |

## 1. Бета, меняющаяся во времени (фильтр Калмана)

$$
r_t = \alpha + \beta_t m_t + e_t,\ e_t\sim N(0,r), \qquad \beta_t = \beta_{t-1} + w_t,\ w_t\sim N(0,q)
$$

`r_t` доходность акции, `m_t` доходность домашнего бенчмарка того же дня. Бета следует случайному
блужданию. Шаги фильтра: прогноз `β_{t|t-1} = β_{t-1|t-1}`, `P_{t|t-1} = P_{t-1|t-1} + q`;
инновация `v_t = r_t − α − β_{t|t-1} m_t`, `F_t = m_t² P_{t|t-1} + r`; усиление `K_t = P_{t|t-1} m_t / F_t`;
обновление `β_{t|t} = β_{t|t-1} + K_t v_t`, `P_{t|t} = (1 − K_t m_t) P_{t|t-1}`.

Параметры `q` и `r` подбираются максимумом правдоподобия ошибок одного шага,
$\ell = -\tfrac12\sum(\ln F_t + v_t^2/F_t)$, оптимизацией по `x0 = ln(q·var(m)/s²)`, `x1 = ln(r/s²)`
(`s²` дисперсия остатков МНК). Свободный член `α` исключён из правдоподобия точно (GLS по инновациям,
фильтр линеен по наблюдениям). Первые 5–20 наблюдений (`n/10`) — разгон и в правдоподобие не входят.
Мягкий штраф держит `q` и `r` около стартовой точки. Выход: ряд `β_t`, его стандартные ошибки,
последняя бета и её ошибка.

**Когда честно возвращается `null`:** меньше 60 наблюдений; бенчмарк почти постоянен; точная линейная
связь; `r` упёрлось в нижнюю границу или `q` в верхнюю (тогда `β_t` просто интерполирует доходности).

**Ограничения.** Гауссовы ошибки (хвосты тяжелее); бета меняется гладко, скачок размазывается;
`α` постоянна; бенчмарк домашний, а не глобальный; нелдер-Мид может остановиться в локальном максимуме
(поэтому стартов несколько); интервал `β ± 2·std` учитывает только шум фильтра, не риск модели.

## 2. Режимы: скрытая марковская модель с двумя состояниями

Состояние `S_t ∈ {0 «спокойно», 1 «турбулентно»}`, переходы `P(S_t=j | S_{t-1}=i) = A_ij`, доходность
`r_t | S_t=k ~ N(μ_k, σ_k²)`. Начальные вероятности фиксированы 0.5 (не оцениваются). Обучение: EM
(Баум-Велч) с масштабированными прямой и обратной рекурсиями. Старты: дни, где локальное квадратичное
отклонение выше квантилей 0.5, 0.75, 0.9; лучший старт доучивается до 400 итераций (допуск 1e-6).
Дисперсия состояния не меньше 5 % выборочной сигмы, вероятность перехода не ближе 1e-6 к границе.

Выход: `P(S_t=1 | r_1..r_t)` (фильтрованная вероятность, без заглядывания вперёд при **фиксированных**
параметрах, оценённых по всей выборке), параметры состояний, матрица переходов, ожидаемая
длительность `1/(1 − A_kk)`.

Результат отвергается (`null`), если: `σ_1/σ_0 < 1.25`; ожидаемая длительность состояния меньше 3
дней (это тяжёлые хвосты, а не режим); состояние занято меньше 8 дней или 2 % выборки; выигрыш
логарифмического правдоподобия над одним гауссовым состоянием не превышает штраф BIC: `2·ln(n)` (4 лишних параметра, `0.5·4·ln n`).

**Ограничения.** Параметры подогнаны по всей истории, поэтому прошлые вероятности режима «знают» о
будущем через параметры; два режима упрощение (кризис и обычный всплеск смешиваются); модель
не предсказывает смену режима, а описывает текущую вероятность.

## 3. Точки перелома (Адамс и Маккей, 2007)

Байесовское онлайн-обнаружение смены среднего или дисперсии. Сегмент гауссов с неизвестными средним и
дисперсией, сопряжённый приор Normal-Inverse-Gamma (`κ₀ = 0.1`, `α₀ = 2`, масштаб = MAD·1.4826
первых ≤50 наблюдений; окно, решающее `recentProbability`, свой приор не калибрует). Предсказательное
распределение: Стьюдент. Рекурсия по длине серии `r_t`:

$$
P(r_t = 0 \mid x_{1:t}) \propto \sum_{r} P(r_{t-1}=r)\, \pi(x_t \mid r)\, H, \qquad
P(r_t = r+1 \mid x_{1:t}) \propto P(r_{t-1}=r)\, \pi(x_t \mid r)\,(1-H)
$$

`H = 1/60` — априорная частота смены (в среднем раз в 60 сессий). Сигнал: `P(r_t ≤ 5)`, вероятность,
что свежий сегмент начался в последние 5 дней. Перелом фиксируется, только если наиболее вероятный
сегмент не короче 10 наблюдений **и** в окрестности его начала (±5) накоплено хотя бы 0.5 массы.
Хвост распределения отбрасывается при массе ниже 1e-8·H.

**Ограничения.** `H` и приор задают чувствительность: при `H`→1 «переломов» станет много. Список
`breaks` может пересматриваться по мере поступления данных (ряд `changeSeries`, наоборот, не
заглядывает вперёд, начиная с `t = 49`). Модель не отличает смену режима от разовой новости.

## 4. Проверка

`node api/_dossier/math/backtest.mjs` прогоняет на синтетически сгенерированных рядах с известной истиной
(HMM, скачки) и на реальных фикстурах, если они есть, и печатает покрытие VaR, частоту ложных
скачков и покрытие коридора прогноза. Подробности и последние числа в разделе «Калибровка»
[`volatility-risk.md`](volatility-risk.md) и в самом выводе скрипта.
