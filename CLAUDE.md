# Money Bansho: ознакомление для следующего Claude

Прочитай этот файл целиком перед работой. Отвечай пользователю по-русски. Сроки хакатона очень жёсткие (27.11.2026 вечером оставалось меньше 3 часов).

## Что это

Финансово-геополитический дашборд: как акции компаний двигаются на фоне экономики, политики и внутренних событий (смена CEO и ключевых людей), репутация компании, свежие новости. Особый упор на источники Китая, Европы, Израиля и о КНДР.

Основа: [World Monitor](https://github.com/koala73/worldmonitor), коммит `7d5083c4`, Copyright (C) 2026 Elie Habib, **AGPL-3.0**.

## Решения пользователя (не переспрашивать)

- Главное на демо: **досье компании** (`/dossier.html`), около 50 компаний мира.
- Только бесплатные источники без ключей.
- Стиль: тёмный терминал, статичный и солидный. Без градиентов, свечений, пульсаций, эмодзи, значков «AI», «beta», «new», промоблоков.
- Нужна публичная ссылка для жюри.
- Пуш прямо в `main`.

## Обязательные правила

- `LICENSE` (AGPL-3.0), копирайты и пометку «Based on World Monitor» со ссылкой сохранять. Пользователь говорил, что есть письменное разрешение автора, но его объём не показан: лицензию не менять.
- Бренд и логотип World Monitor не использовать. Идентификаторы кода (proto, пути `server/worldmonitor`, заголовки, переменные окружения, ключи localStorage) **не переименовывать**.
- Данные не выдумывать: при сбое показывать «нет данных».
- Не коммитить секреты. Отключение защит (в том числе ограничения частоты запросов) только после явного согласия пользователя.
- `AGENTS.md`, `ARCHITECTURE.md`, `docs/` остались от оригинала и описывают upstream.

## Запуск и проверки

```bash
npm install                 # желателен Node 24 (.nvmrc); локально работало и на Node 26
npm run dev                 # http://localhost:3000/dossier.html и /dashboard
node node_modules/@typescript/native/bin/tsc --noEmit
node --test api/_dossier/*.test.mjs
npm run lint:api-contract
npm run build:deploy        # сборка для Vercel, см. DEPLOY.md
```

Первый старт Vite занимает 20–60 секунд.

## Карта досье

| Путь | Что там |
|---|---|
| `dossier.html`, `src/dossier/**` | интерфейс без фреймворков, свой SVG-график, EN/RU, `?symbol=&range=` |
| `api/dossier.js` | edge-функция: `?symbol=X&range=1mo\|3mo\|1y`, `?view=board`, `?view=wire` |
| `api/_dossier/` | Yahoo chart, Google News RSS (en, zh, he, de, fr, ko), SEC 8-K 5.02, фильтр рекламы (`events.js`) |
| `api/_dossier/analyze.js` | тип события, тональность, имена, дедупликация, реакция цены, репутация |
| `shared/dossier-companies.json` | 61 компания. **Три копии держать одинаковыми:** этот файл, `scripts/shared/dossier-companies.json`, `api/_dossier/companies.js` |
| `src/styles/bansho-theme.css` | тема дашборда (подключена из `base-layer.css`) |
| `NOTICE.md`, `DEPLOY.md` | атрибуция и инструкция по деплою |

Репутация: `50 + 50 * sum(вес * тональность) / (sum(вес) + 3)`, полураспад 14 дней, окно 90 дней.

## Известные ограничения

- Новости обновляются опросом (досье 20 с, лента 30 с), не посекундно. Жюри этого не обещать.
- Анализ по ключевым словам: заголовок с именем без должности может не распознаться как смена руководства; чужие назначения иногда приписываются упомянутой компании.
- Google News RSS иногда отвечает 429; условия ленты разрешают только личное некоммерческое использование.
- Официальных лент КНДР найти не удалось.
- Часть тестов оригинала (бренд, `vercel.json`, удалённые README) ожидаемо падает; в `edge-functions.test.mjs` было 4 падения. CI и git-хуки оригинала не перенесены.
