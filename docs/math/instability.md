# Индекс нестабильности и риска стран

Код: `api/_dossier/math/instability.js` (математика), `api/_dossier/instability-data.js` (данные),
`GET /api/dossier?view=instability[&country=UA][&tl=ru]`. Интерфейс: клиентские данные
`src/services/bansho-country-index.ts`, карточка страны `src/shell/bansho-index-view.ts`, блок
доказательств `src/shell/bansho-index-proof.ts`, раздел рейтинга `src/shell/bansho-instability.ts`.
Это единственный индекс стран на дашборде: панель страны, раскраска карты, поиск, списки и карточки
для публикации берут числа отсюда; унаследованный индекс оригинала не запрашивается.

Индекс показывает, насколько сегодняшние рынки и новости страны **отклоняются от нормы** в сторону
риска. Это не вероятность кризиса и не абсолютный уровень опасности. Значение 50 имеет агрегат, у
которого все компоненты стоят на медиане; из-за взвешивания хвостов и стресс-члена типичная страна с
разнородными компонентами обычно оказывается выше 50. Значения вычисляются с плавающей точкой и
показываются с четырьмя знаками. **Эти знаки — результат расчёта, а не точность измерения**: реальную
неопределённость показывает интервал (обычно несколько пунктов и больше).

## Источники

- Yahoo Finance, дневные цены за 2 года: индекс акций и курс местной валюты к доллару.
  Для США вместо курса берётся индекс доллара DXY с обратным знаком. Страны еврозоны делят один курс EUR,
  поэтому их валютные компоненты совпадают: это один и тот же ряд.
  Для Польши и Саудовской Аравии используются биржевые фонды (прокси, указано в ответе; фонд KSA
  номинирован в USD). Курс саудовского риала исключён явно: он привязан к доллару, а колебания в Yahoo —
  шум котировок. Курс IRR=X исключён: это официальный, а не рыночный курс.
- Публичные RSS-ленты из `world.js`, окно 7 суток. Исключены поисковые ленты Google News (они отбирают
  новости по теме и смещают доли) и китайскоязычная лента (словарь тона английский).
- GDELT DOC 2.0, объём за 3 месяца для выбранной страны. Только справочно: из-за ограничения частоты
  запросов он доступен не для всех стран одновременно и в индекс не входит.

## Подготовка рядов

Плохой тик удаляется, если доходность превышает max(8 σ_rob, 3 %) и следующий день возвращает не менее
70 % этого движения. Ряд не используется (компонент отсутствует), если: он не обновлялся более 10 суток;
в нём меньше 151 наблюдения; валюта фактически фиксирована (более 40 % нулевых изменений или годовая
волатильность ниже 1 %).

## Условная волатильность

GARCH(1,1) со стандартизованными инновациями Стьюдента, максимум правдоподобия с таргетированием
дисперсии (см. `volatility-risk.md`):

    σ²_{t+1} = ω + α ε²_t + β σ²_t

Модель берётся, если оптимизация сошлась, α > 0,01 и α + β > 0,5. Иначе — EWMA:
σ²_{t+1} = 0,94 σ²_t + 0,06 r²_t. Использованная модель и параметры возвращаются для каждого ряда.
Параметры GARCH оцениваются по всей двухлетней выборке, поэтому в **истории** графика есть заглядывание
в будущее через параметры (но не через саму рекурсию и не через эталон стандартизации).

## Признаки (больше — рискованнее)

P_t — цена индекса, Q_t — число единиц местной валюты за доллар, σ_t — условная дневная волатильность,
известная на закрытии t.

| id | признак x_t | базовый вес |
|---|---|---|
| eqVol | ln σ_t | 0,18 |
| eqDrawdown | 1 − P_t / max(P_{t−125..t}) | 0,15 |
| eqShock | −ln(P_t / P_{t−5}) / (σ_{t−5} √5) | 0,12 |
| fxVol | ln σ_t курса | 0,12 |
| fxDep | ln(Q_t / Q_{t−21}) / (σ_{t−21} √21), для DXY со знаком минус | 0,13 |
| newsVolume | статистика всплеска объёма | 0,12 |
| newsTone | сжатая доля негативных заголовков | 0,18 |

Базовые веса, степень p и коэффициент β **экспертные**, по историческим данным не оценивались.

## Робастная стандартизация

Для рыночных признаков эталон — собственные 252 наблюдения **строго до** дня t (минимум 120):

    m = median(x),  s = 1,4826 · median|x − m|,   z_t = (x_t − m) / s

Если MAD = 0, берётся 1,2533 · среднее |x − m|; если и оно равно нулю, значения нет.

## Новости

Страна «упомянута», если заголовок содержит её название, прилагательное, столицу или имя лидера.

**Объём.** Каждому заголовку ленты f присваивается свежесть a = 2^(−возраст / 24 ч). Стратифицированный
перестановочный тест (расширение Мантеля теста Кокрана — Мантеля — Хензеля): N_f заголовков, из них m_f
о стране с суммой свежести x_f; ā_f и s²_f — среднее и дисперсия a в ленте. Под гипотезой «заголовки о
стране не свежее остальных»:

    E_f = m_f ā_f,   V_f = m_f s²_f (N_f − m_f) / (N_f − 1)
    z_raw = Σ(x_f − E_f) / sqrt(Σ V_f)

Состав лент и глубина их архивов сокращаются; жёсткой границы «24 часа» нет. Заголовки об одном сюжете
зависимы, поэтому z = z_raw / φ, φ = max(1, 1,4826 · median_c |z_raw,c|) (эмпирическое нулевое
распределение). Нужно не менее 5 упоминаний в информативных лентах.

**Тон.** Вес заголовка w = 2^(−возраст / 72 ч). Доля негативных (по словарю `headlineTone`)
q = Σ w·[негативный] / Σ w, эффективный объём по Кишу n = (Σw)² / Σw². p₀ — та же доля по всему корпусу.
Бета-биномиальное сжатие и сравнение между странами:

    p̃ = (n q + 20 p₀) / (n + 20)
    z = (p̃ − p₀) / max(1,4826 · MAD_c p̃, 0,05)

Нужно не менее 5 заголовков о стране (и не менее 5 таких стран).

## Балл компонента

Вместо обрезания |z| используется гладкое сжатие хвостов и функция распределения Стьюдента с 4
степенями свободы (замкнутая формула), поэтому балл строго возрастает и не образует «ступенек»:

    z̃ = 3 · asinh(z / 3)
    s = 100 · T₄(z̃),   T₄(t) = 1/2 + (3/8) · (t/√(1 + t²/4)) · (1 − t² / (12 (1 + t²/4)))

## Корреляции компонентов

Матрица R 7×7 блочно-диагональная.

- Рыночный блок 5×5: корреляции Пирсона дневных z̃, объединённые по странам (с вычитанием средних
  внутри страны). Эффективное число наблюдений n_eff = n / 20 из-за автокорреляции.
- Новостной блок 2×2: корреляция между странами на текущую дату, n_eff = число стран.
- Связи «рынок — новости» приняты равными нулю: истории новостей нет.

Каждый блок сжимается к единичной матрице с интенсивностью Шефера — Штриммера:

    λ = min(1, max(0,1, Σ_{i<j} (1 − r²_ij)² / (n_eff − 1)  /  Σ_{i<j} r²_ij)),   R_ij = (1 − λ) r_ij

Страны с общей валютой входят в оценку валютных пар несколько раз — это упрощение.

## Агрегация

Только по доступным компонентам (k штук, R — соответствующая подматрица).

1. Веса с поправкой на избыточность: коррелированные компоненты не учитываются дважды.

       w̃_i = (w_i / Σ_j max(R_ij, 0)),  затем нормировка Σ w̃ = 1

2. Среднее степени p = 2 — высокие баллы весят больше, чем в среднем арифметическом:

       M = (Σ w̃_i s_i²)^(1/2)

3. Односторонний стресс Махаланобиса (статистика Кудо): расстояние от z̃ до множества «всё не выше
   нормы» в метрике R⁻¹:

       D² = min_{v ≤ 0} (z̃ − v)ᵀ R⁻¹ (z̃ − v)

   Равносильно D² = min yᵀR⁻¹y по y ≥ z̃ (y = z̃ − v). Решается покоординатным спуском (не более
   5000 проходов, остановка при изменении меньше 10⁻¹²). Если R не положительно определена (парные
   оценки не обязаны давать такую матрицу), вместо R⁻¹ берётся единичная матрица. Свойства доказаны
   ниже; кроме того, при k = 2, r ≥ 0 и двух положительных сигналах D не больше, чем у независимых.

4. Логистическое объединение:

       Q = 100 · Λ( logit(M/100) + 0,25 · D / √k ),   Λ(x) = 1 / (1 + e^(−x))

### Вклады

Точные значения Шепли по всем 2^k подмножествам (отсутствующий в подмножестве компонент ставится в
z = 0, веса и R фиксированы):

    φ_i = Σ_{S ⊆ N∖{i}} |S|! (k − |S| − 1)! / k! · [ v(S ∪ {i}) − v(S) ],   v(∅) = 50

## Эмпирическое байесовское сжатие

θ = logit(Q/100), σ — стандартная ошибка θ из бутстрэпа. Априорное распределение между странами оценено
методом моментов по странам с покрытием C ≥ 0,5 (нужно не менее 5):

    μ = среднее θ,   τ² = max(Var θ − среднее σ², 0,1 · Var θ)

Отсутствующий вес добавляет дисперсию:

    v = σ² + τ² (1 − C) / C,   B = τ² / (τ² + v)
    I = 100 · Λ( μ + B (θ − μ) )

Чем меньше покрытие и надёжность, тем ближе индекс к среднему по странам и тем шире интервал.
Разложение в интерфейсе: **I = 50 + Σ φ_i + Δ**, где Δ = I − Q — поправка сжатия.

## Интервал неопределённости (90 %)

    [ 100·Λ(μ + B(θ − μ) − 1,645 √(B v)),  100·Λ(μ + B(θ − μ) + 1,645 √(B v)) ]

σ получается из 200 повторов с фиксированным зерном (числа не меняются без изменения данных):

1. рыночные компоненты: эталон перевыбирается циклическим блочным бутстрэпом (блок 20 дней);
2. объём: z + ε, ε ~ N(0, 1);
3. тон: биномиальная перевыборка n эффективных заголовков с долей p̃;
4. базовые веса: w_i · g_i, g_i ~ Gamma(25, 1/25) (разброс 20 %).

Интервал **не** учитывает ошибки поставщиков данных, выбор p и β, неопределённость R, μ, τ², параметров
GARCH, центра и разброса тона, поэтому занижает полную неопределённость.

## Доказательства свойств

Обозначения: s_i — балл, w̃_i — веса после поправки, M — среднее степени p = 2, D — расстояние,
k — число доступных компонентов, Λ — логистическая функция, B — надёжность, C — покрытие. Те же
теоремы с числами выбранной страны показаны в интерфейсе («Расчёт по шагам и математические
доказательства»). Каждое свойство проверяется на случайных входах (сотни наборов компонентов,
значения z от долей единицы до миллионов, положительно и не положительно определённые R) в
`api/_dossier/math/instability-proofs.test.mjs`.

### Теорема 1. Ограниченность

    0 < s_i < 100,   min s ≤ M ≤ max s,   M ≤ Q < 100,   0 ≤ I_низ ≤ I ≤ I_верх ≤ 100

Доказательство. T₄ — функция распределения, её значения лежат строго между 0 и 1. Веса w_i > 0, а
r_i = Σ_j max(R_ij, 0) ≥ R_ii = 1, поэтому w̃_i > 0 и Σ w̃_i = 1: M² — выпуклая комбинация s_i².
D ≥ 0, β > 0, logit и Λ возрастают, поэтому Q = 100·Λ(logit(M/100) + β D/√k) ≥ M. Значения Λ лежат
в (0; 1). Полуширина интервала неотрицательна, Λ возрастает. ∎

Оговорка о коде: аргумент logit и Q/100 ограничены отрезком [10⁻¹²; 1 − 10⁻¹²], чтобы θ оставалось
конечным; поэтому M ≤ Q выполняется с точностью 10⁻⁹.

### Теорема 2. Монотонность по каждому компоненту

При неизменных наборе компонентов, R и весах увеличение любого z_i увеличивает s_i, M и Q и не
уменьшает D. При неизменных σ, C, μ, τ² индекс I возрастает по θ = logit(Q/100).

Доказательство. z̃ = 3·asinh(z/3) строго возрастает, T₄′ — плотность, она положительна: s_i и M
возрастают. Пусть z̃′ ≥ z̃ покомпонентно. Всякий y ≥ z̃′ удовлетворяет и y ≥ z̃, то есть минимум для
z̃ берётся по большему множеству: D(z̃) ≤ D(z̃′). Это верно при любой положительно определённой P и
любых знаках корреляций. Сумма logit(M/100) + βD/√k возрастает, значит возрастает Q. Наконец,
logit(I/100) = μ + B(θ − μ), B > 0. Наблюдение входит в z как (x − m)/s с s > 0, поэтому при
неизменном эталоне то же верно по x (для тона — при неизменных p₀ и d, для объёма — при неизменном φ). ∎

Чего не утверждается: при полном пересчёте на новых данных меняются эталон, R, p₀, d, φ, μ, τ² и
σ (а с ним B), и монотонность I по сырому наблюдению тогда не гарантируется. Пропажа или появление
компонента может сдвинуть индекс в любую сторону. В арифметике с плавающей точкой при огромных |z|
строгое неравенство может стать равенством (в пределах ошибки округления).

### Теорема 3. Пропущенные данные

1. Отсутствующий компонент не входит ни в M, ни в D и ничем не заменяется: результат совпадает с
   расчётом по набору доступных. C = Σ w_i доступных; при C < 0,25 ни Q, ни I не вычисляются.
2. При наличии априорного распределения B = 1 / (1/C + σ²/τ²) ≤ C, то есть собственные данные страны
   весят не больше её покрытия, и |logit(I/100) − μ| ≤ C·|θ − μ|. При σ = 0 имеем B = C.
3. Полуширина интервала на шкале logit равна 1,645·τ·√(1 − B) и растёт при уменьшении C.

Доказательство. Первое — по построению (в расчёт берутся только конечные z). v = σ² + τ²(1 − C)/C,
поэтому τ² + v = τ²/C + σ², и B = τ²/(τ² + v) = 1/(1/C + σ²/τ²) ≤ C. Далее
logit(I/100) − μ = B(θ − μ). Наконец, B·v = τ²·v/(τ² + v) = τ²(1 − B), а B убывает вместе с C. ∎

Оговорки: свойства 2 и 3 — при неизменных θ, σ, μ, τ². Если стран для априорного распределения
меньше пяти, B = 1, v = σ², и покрытие на сжатие не влияет. Ширина интервала в пунктах индекса (а не
на шкале logit) монотонной по C не обязана быть: вместе с B сдвигается центр.

### Теорема 4. Чувствительность к базовым весам

D не зависит от весов. Обозначим q = Q/100, m = M/100. Тогда

    ∂Q/∂w_i = q(1 − q) / (m(1 − m)) · w̃_i (s_i^p − M^p) / (p · w_i · M^(p−1)),    Σ_i w_i ∂Q/∂w_i = 0

Для любых положительных весов Q лежит между Q(min s) и Q(max s), где
Q(s) = 100·Λ(logit(s/100) + βD/√k). Крайние значения Q при изменении каждого веса не более чем на
±20 % достигаются в вершинах этой коробки; все 2^k вершин перебираются.

Доказательство. M^p = Σ a_i w_i s_i^p / Σ a_i w_i, a_i = 1/r_i. Отсюда ∂M^p/∂w_i = (w̃_i/w_i)(s_i^p − M^p),
дальше правило цепочки; Σ w̃_i (s_i^p − M^p) = M^p − M^p = 0. При любых положительных весах M^p —
выпуклая комбинация s_i^p. Отношение линейных функций с положительным знаменателем монотонно по
каждой переменной, поэтому экстремумы на коробке — в вершинах. ∎

Оговорка: изменение весов меняет и покрытие C; приведённые границы относятся к Q. Для I они
пересчитываются при неизменных C, σ, μ, τ² (I возрастает по Q по теореме 2).

### Теорема 5. Вклады

    Σ_i φ_i = Q − 50;    z_i = 0 ⇒ φ_i = 0;    z_i · φ_i ≥ 0

Доказательство. Для любого порядка добавления компонентов сумма приращений v телескопически равна
v(N) − v(∅); φ — их среднее по всем k! порядкам. При всех z = 0: s = 50, M = 50, D = 0, v(∅) = 50.
Если z_i = 0, добавление i не меняет ни одного аргумента v. По теореме 2 приращение
v(S ∪ {i}) − v(S) имеет знак z_i или равно нулю. ∎

Показываемое разложение: I = 50 + Σ φ_i + (I − Q).

### Теорема 6. Найденное расстояние — минимум

Если y* ≥ z̃, g = P y* ≥ 0 и g_i (y*_i − z̃_i) = 0 для всех i, а P положительно определена, то y* —
глобальный минимум yᵀPy на y ≥ z̃. D = 0 тогда и только тогда, когда все z_i ≤ 0.

Доказательство. f(y) = yᵀPy выпукла, поэтому f(y) ≥ f(y*) + 2g·(y − y*). Для допустимого y:
g·(y − y*) = g·(y − z̃) − g·(y* − z̃) = g·(y − z̃) ≥ 0. Если все z̃ ≤ 0, то y = 0 допустим и D = 0.
Если D = 0, то y* = 0 (P положительно определена), а y* ≥ z̃. ∎

Условия проверяются на каждой стране: их невязка пересчитывается в браузере и показывается.

### Проверка в интерфейсе

Ответ сервера содержит поле `proof` с полной точностью: входы нормировки каждого компонента (x,
медиана, разброс, даты эталона; суммы теста свежести; доли тона), z, веса, R, P, y*, g, M, D, Q,
чувствительность и параметры сжатия. Браузер заново считает M, Q, I и границы интервала своей
реализацией формул (из z, базовых весов, R, P и y*) и показывает расхождение с опубликованными
числами. Это проверяет согласованность расчёта, но не качество исходных данных.

## Покрытие, рейтинг, регионы

Отсутствующий компонент не заменяется никаким значением. C = доля базового веса доступных компонентов.
При C < 0,25 индекс не публикуется («нет данных»). Страны с C < 0,5 выводятся после остальных без номера
в рейтинге и не входят в региональные средние. Достоверность: «высокая» — C ≥ 0,85 и не менее 20
заголовков; «средняя» — C ≥ 0,5; иначе «низкая». Индекс региона — простое среднее по его странам.

## История

Строится только для рыночной части: на каждую дату календаря индекса акций (или валюты, если акций нет)
вычисляется агрегат Q по рыночным компонентам (без новостей и без сжатия) с тем же набором компонентов,
что сегодня; значения другого ряда берутся не старше 7 дней. Матрица R — сегодняшняя. Поэтому последняя
точка графика не равна индексу.

## Ограничения

- Теоремы выше описывают свойства формулы, а не её способность предсказывать события.
- Индекс не проверялся на предсказательную силу.
- Yahoo Finance не даёт индексов акций Украины, Ирана и КНДР; у части рядов бывают пропуски и ошибки.
- Управляемые курсы отражают политику регулятора, а не только рынок.
- Тон по словарю ключевых слов груб; заголовки англоязычные, в основном западные.
- Упоминание страны не означает, что событие происходит в ней.
