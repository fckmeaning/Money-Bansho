# Проверка весов и полураспадов на реальной истории

Скрипты: [`scripts/backtest-fetch.mjs`](../../scripts/backtest-fetch.mjs) (скачивает данные) и
[`scripts/backtest-real.mjs`](../../scripts/backtest-real.mjs) (считает, офлайн, детерминированно, около 20 с).
Данные: `docs/handoff/backtest-data/` (около 0.7 МБ). Это отчёт, а не ворота: код выхода всегда 0.

Веса и полураспады из `quant.js` и `forecast.js` раньше были выбраны по смыслу. Здесь они впервые сверены
с реальными ценами. Вывод не обещает цену: проверяется только, насколько сигналы досье согласуются с
размером и направлением следующих движений.

## 2. Метод

Без заглядывания вперёд: сигнал в конце сессии `i` считается теми же функциями, что и в коде
(`companySignals`, `eventStudy`, `computeForecasts`), на истории не длиннее 300 сессий до `i`; цель
берётся только после `i`. Копии формул в скрипте сверены с кодом (индекс внимания: 4720 из 4720 дней совпали;
оценщик прогноза: максимальное расхождение `mu` 6.5e-7 на 30 событиях).

* **Показатель** для весов и затухания: средний по бумагам ранговый коэффициент Спирмена `rho` между сигналом
  и целью. Цели: `|r|` на `i+1` (`y1`), средний `|r|` за 5 (`y5`) и 20 (`y20`) сессий (размер движения; индекс
  внимания не направленный) и знаковая избыточная доходность (бумага минус индекс) за 5 и 20 сессий
  (`a5`, `a20`: контроль, `rho` должен быть около нуля).
* **Доверие**: 95 % интервал блочного бутстрэпа (блоки по 30 календарных дней, одни и те же дни для всех бумаг:
  учитывается общая рыночная зависимость); p-значение по перестановкам циклическим сдвигом цели (сохраняет
  автокорреляцию); поправка на множественные проверки Бенджамини-Хохберга, FDR 10 %. 400 повторов, seed
  фиксирован. Разность двух сигналов считается на тех же бутстрэп-выборках.
* **Walk-forward**: веса подбираются по сетке (шаг 0.1) на первых 60 % календаря (до 2025-01-28), качество
  измеряется на последних 40 %.
* **Прогноз**: для каждого реального события (8-K типов `earnings`, `leadership`, `deal`, у которого уже есть
  не меньше 5 непересекающихся аналогов того же типа) прогноз строится по истории до события, итог сравнивается
  с реальным закрытием через 1, 5, 20 сессий. Оценка: нормальная логарифмическая плотность (логскор), покрытие 80 %,
  MSE относительно нулевого прогноза; интервалы разностей бутстрэпом по событиям.
* Статистики считаются по бумаго-дням, которые автокоррелированы; интервалы блочного бутстрэпа это учитывают,
  p-значение Купьеца для VaR ориентировочное.

## 3. Результаты

### 3.1 Веса индекса внимания

Панель: 31 бумага, 32 952 бумаго-дня, 2022-06 .. 2026-10. Новостей в панели нет (раздел 1), поэтому сравниваются
три компоненты, остальные веса перенормируются так же, как это делает код. `*` значимо после FDR против `rho = 0`.

| Сигнал | y1 | y5 | y20 | a5 | a20 |
|---|---|---|---|---|---|
| прежние 0.4 / 0.2 / 0.1 | 0.071* | 0.085* | 0.063* | 0.005 | 0.008 |
| **равные 1/3** (теперь в коде) | **0.085*** | **0.105*** | **0.078*** | 0.004 | 0.004 |
| только цена | 0.047* | 0.060* | 0.048* | 0.006 | 0.007 |
| только объём | 0.086* | 0.076* | 0.040* | −0.004 | 0.011 |
| только волатильность | 0.055* | 0.085* | 0.073 | −0.007 | −0.018 |
| цена + объём | 0.073* | 0.079* | 0.055* | 0.003 | 0.010 |
| для сравнения: вчерашний модуль доходности | 0.068* | 0.121* | 0.140* | −0.003 | 0.002 |
| для сравнения: `rv20` (уровень волатильности) | 0.137* | 0.258* | 0.324* | 0.009 | 0.012 |

* Прежние минус равные: −0.015 [−0.019; −0.010] (q = 0.005), −0.020 [−0.029; −0.009] (q = 0.005),
  −0.015 [−0.027; −0.001] (q = 0.057). Равные лучше на всех трёх горизонтах.
* Цена как единственная компонента слабее объёма на `y1` и слабее волатильности на `y5`, `y20`; прежние минус «только цена»
  +0.024 / +0.024 / +0.015: основной вес 0.4 стоял на компоненте, которая сама по себе информативнее всего не была.
* Walk-forward. Лучшие веса на обучении (цена / объём / волатильность): 0.10 / 0.80 / 0.10 (`rho` на обучении 0.077
  против 0.061 у прежних). На проверке (после 2025-01-28):

  | Горизонт | подобранные | прежние | равные |
  |---|---|---|---|
  | y1 | 0.113 | 0.085 | 0.107 |
  | y5 | 0.125 | 0.112 | **0.148** |
  | y20 | 0.094 | 0.095 | **0.123** |

  Прежние минус равные на проверке: −0.022 [−0.028; −0.015], −0.036 [−0.049; −0.020], −0.028 [−0.047; −0.008], все
  p = 0.002 (минимум при 400 повторах). Подобранные веса лучше прежних только на `y1` (+0.028 [0.017; 0.043]),
  на `y5` и `y20` не отличимы (+0.012 [−0.007; 0.031], −0.001 [−0.020; 0.022]) и не лучше равных. Поэтому в коде
  равные веса (правило 1/N), а не подобранные: подбор не удержался вне выборки.
* Направленность: `a5` и `a20` для всех вариантов около нуля и не значимы: индекс, как и заявлено, не говорит
  о направлении.
* Честная оговорка о величине: `rho` 0.07–0.1 мало. Индекс измеряет «насколько день необычен для этой
  компании» (отношения к её же норме), а не уровень будущей волатильности; уровень `rv20` предсказывает размер
  движений заметно лучше (0.14 / 0.26 / 0.32). Индекс не заменяет прогноз волатильности (для него есть GARCH
  во вкладке «Модель»).

**Новости (вес 0.3)**: нет данных, см. раздел 1.

### 3.5 Прогноз «новость → сценарий»: сжатие и коридор

Реальные события 8-K 9 компаний США с не менее чем 5 аналогами: `h = 1`: 246 событий (earnings 155, leadership 70,
deal 21), `h = 5`: 243, `h = 20`: 222. Пул аналогов только по типу (тона нет). «Нулевая» модель: `mu = 0`,
`sd = sigma·sqrt(h)`.

| h | Вариант (PRIOR среднего / дисперсии) | Логскор против нулевой | Против прежнего | Покрытие 80 % | MSE / MSE(0) | Знак |
|---|---|---|---|---|---|---|
| 1 | нулевая | 0 | | 52.4 % | 1.000 | 45.9 % |
| 1 | прежнее 10 / 10 | +2.139 [1.329; 3.160] | | 71.5 % | 1.017 | 46.7 % |
| 1 | **теперь 30 / 5** | +2.217 [1.371; 3.259] | **+0.079 [0.042; 0.121]** | 75.2 % | 1.005 | 46.7 % |
| 1 | `mu = 0`, дисперсия 2 | +2.254 [1.371; 3.300] | +0.116 [0.054; 0.187] | 78.0 % | 1.000 | |
| 5 | нулевая | 0 | | 60.9 % | 1.000 | 50.6 % |
| 5 | прежнее 10 / 10 | +0.299 [0.132; 0.502] | | 69.1 % | 1.040 | 46.5 % |
| 5 | **теперь 30 / 5** | +0.314 [0.128; 0.541] | +0.015 [−0.025; 0.049] | 71.6 % | 1.019 | 46.5 % |
| 20 | нулевая | 0 | | 74.8 % | 1.000 | 51.4 % |
| 20 | прежнее 10 / 10 | −0.003 [−0.082; 0.076] | | 75.2 % | 1.043 | 50.9 % |
| 20 | **теперь 30 / 5** | −0.005 [−0.091; 0.080] | −0.002 [−0.024; 0.017] | 76.6 % | 1.018 | 50.9 % |

Что видно:

1. **Среднее аналогов не лучше нуля**: MSE относительно нулевого прогноза больше 1 при любом `PRIOR` не больше 20
   (1.008–1.131), доля угаданных знаков 46–51 %. На реальных событиях тип без тона не даёт направления. Поэтому среднее
   теперь сжимается сильнее (`PRIOR_MEAN = 30`).
2. **Разброс аналогов полезен**: в день отчётности модуль аномальной доходности в среднем примерно втрое больше обычного (раздел 3.3), и
   нулевой коридор покрывает лишь 52 % на горизонте 1 сессия. Аналоги это ловят; прежнее сжатие дисперсии к обычной
   (`PRIOR = 10`) расширяло коридор недостаточно (71.5 %), с `PRIOR_VARIANCE = 5` покрытие 75.2 %, логскор лучше на 0.079
   (значимо на `h = 1`, на `h = 5` и `h = 20` разница не отличима от нуля).
3. **Покрытие 80 % в дни событий остаётся ниже номинала** (75.2 / 71.6 / 76.6 %): аналогов мало (в среднем 11–13),
   хвосты тяжёлые, события и окна пересекаются. Интерфейс не должен читать коридор как «80 % вероятности»; в
   `docs/math/forecast.md` это отмечено. Более сильная поправка (квантили Стьюдента для малых `n`, расширение
   коридора) не внесена: проверка заняла бы больше времени, чем было, и должна быть отдельной.
4. **Не проверено**: часть «тон» правил `type+tone` и `tone` (нужна история тона заголовков), пулы типов
   `scandal`, `regulation`, `politics`, `product` (в 8-K их нет), компании не из США.

Покрытие базового коридора без событий (`mu = 0`, `sigma_60·sqrt(h)`) на всех днях всех 31 бумаги, шаг 5 сессий,
n = 6697 на горизонт: 83.4 % / 81.4 % / 80.0 % для 1 / 5 / 20 сессий. По регионам (1 / 5 / 20): США 83.6 / 81.2 / 79.3,
Китай 82.5 / 80.6 / 79.7, Европа 83.6 / 81.7 / 81.3, Израиль 84.6 / 82.1 / 80.5, Корея 79.0 / 78.7 / 79.2,
остальные 85.0 / 84.1 / 78.0. В обычные дни коридор откалиброван (на 1 сессию чуть консервативен).

### 3.6 VaR и скачки на реальных ценах (`backtest.mjs --live` и раздел 4 скрипта)

## 5. Ограничения

* 5 лет и 31 бумага: один рыночный режим, период 2021–2026; сильная общая зависимость, поэтому интервалы блочные.
* События 8-K это только компании США (10 штук, по большей части крупные), без тона и без новостей СМИ. Выводы по
  пунктам 8-K не переносятся на новости Google News/GDELT.
* Тон и репутация, вес новостей 0.3, пулы `tone` и `type+tone`: нет данных (раздел 1).
* Цели и сигналы измеряют согласованность, а не причинность; корреляция Спирмена 0.07–0.15 слабая и показывает, что
  ранжирование информативнее случайного, но не годится для торговых решений.
* Выбор «равных весов» и значений `PRIOR` основан на сравнении ограниченного числа вариантов на одной истории; хотя
  проверка вне выборки подтвердила превосходство равных весов, это не доказательство оптимальности.
* Проверенная на 8-K калибровка прогноза (тип без тона) может не воспроизвестись на пулах `type+tone`.
