# Значимость события

Досье оценивает, насколько заметной может оказаться реакция цены на событие, и отдельно показывает, насколько оно актуально сейчас. Расчёт находится в [significance.js](../../api/_dossier/math/significance.js). Для прогноза используется оценка из информации, доступной при публикации заголовка. В ленте событий оценка учитывает и уже наблюдаемую реакцию рынка.

## Оценка при публикации

Начальные шансы зависят от типа события. К их логарифму добавляются поправки на надёжность источника, число подтверждений, силу тона, положение компании в заголовке и новизну.

```text
η = logit(p₀) + 0.8 ln(c / 0.5) + 0.7 ln(n_eff)
    + 1.2 (|tone| − 0.3) + (salience − 0.6) + 0.8 (novelty − 0.7)
n_eff = k / (1 + 0.3 (k − 1))
p_ex = sigmoid(clamp(η, −6, 6))
```

Здесь `k` — число изданий, `c` — надёжность лучшего источника в группе. Новизна убывает с повторением похожих заголовков и событий того же типа. Для прошлых публикаций применяется гауссово ядро с временным масштабом 10 дней, а сходство заголовков измеряется индексом Жаккара. Априорные вероятности и веса заданы вручную.

## Калибровка и рыночная реакция

У аналогов с известным `z` оценивается мягкий индикатор значимой реакции `y = Φ((|z| − 1) / 0.5)`. Остатки `y − p_ex` центрируются относительно компании. Вес аналога задают гауссовы ядра по начальной оценке, тону и разнице дат с масштабами 0.15, 0.5 и 180 дней. У событий другого типа вес уменьшается вчетверо. Калибровочная поправка равна сумме взвешенных центрированных остатков, делённой на сумму весов плюс шесть.

К логарифму шансов калиброванной оценки добавляются два наблюдаемых признака.

- Реакция цены. Двустороннее значение `p` вычисляется по распределению Стьюдента с `ν = max(1, объём выборки − 2)`. Степень неожиданности `min(−ln(p), 6)` получает вес 0.45. Из поправки вычитается средняя поправка по компании со стягиванием к нулю.
- Торговый объём. К отношению с обычным объёмом применяется `0.3 × clamp(log₂(отношение), −1, 3)`.

При пропуске данных соответствующая поправка опускается. Значимость равна `100 × sigmoid(логарифм шансов)`. Диапазон строится как приближённый 80%-ный интервал на шкале логарифмических шансов с последующим обратным преобразованием. Текущая значимость дополнительно умножается на `exp(−age² / (2 τ²))`, где `τ` зависит от типа события.

Ретроспективная калибровка может использовать аналоги, опубликованные позднее рассматриваемого события. Для сценария на момент публикации используется `p_ex`. Значимость описывает величину реакции и не задаёт её направление.
