# Геополитическая оценка точек и событий

Балл от 0 до 100 для точек карты (горячие точки, зоны конфликта, военные базы, ядерные объекты, проливы, а по координатам и любой другой маркер) и для событий мирового обзора. Код: `api/_dossier/math/geoscore.js` (математика), `api/_dossier/geoscore-data.js` (данные). API: `/api/dossier?view=geoscore` (`&point=layer:id`, `&lat=&lon=&name=&country=`, `&limit=`, `&tl=ru`).

## Данные

| Что | Откуда |
| --- | --- |
| Заголовки за 7 дней | ленты мирового обзора без ключей (кроме поисковых Google News и китайских) |
| Индекс нестабильности страны | `view=instability`, см. `instability.md` |
| Зоны конфликта, проливы, ядерные объекты, базы, горячие точки | статичные слои `shared/` |
| Реакция рынков | измеренные z-движения активов у событий мирового обзора |

Точка получает два набора заголовков: о месте (ключевые слова точки или отличительная часть названия объекта) и только о стране.

## Факторы

Каждый фактор лежит в [0, 1] и имеет стандартную ошибку σ. Свежесть заголовка: d = 2^(−возраст / 36 ч).

| Фактор | Вес | Формула | σ |
| --- | --- | --- | --- |
| Всплеск новостей | 0,18 | Φ(z′), z′ = (z / φ) · n / (n + 5) | φ_N(z′) · n / (n + 5) |
| Подтверждение источниками | 0,14 | 1 − e^(−N / 4) | e^(−N/4) / 4 · √Var(N) |
| Тяжесть и негативный тон | 0,16 | T = (Σ ωh + 3h̄) / (Σ ω + 3) | √(s² / (Σ ω + 3)) |
| Нестабильность страны | 0,20 | среднее индекса / 100 | ширина 90% интервала / 3,29 |
| Близость к конфликтам | 0,18 | 1 − Π(1 − aⱼ · e^(−dⱼ² / 2·500²)) | дельта по ширине ядра ±25% |
| Проливы и ядерные объекты | 0,06 | 1 − (1 − K_пролив,600)(1 − 0,5 · K_ядер,300) | то же |
| Реакция рынков | 0,08 | взвешенное по d среднее tanh(\|z\| / 2,5) | дельта при σ_z = 1 |

- **Всплеск.** Тест Кокрана–Мантеля–Хензеля: слой на ленту, сравнивается число упоминаний за 24 ч с ожиданием m·R/N. Поэтому состав лент и глубина их архивов сокращаются. φ — робастный разброс z по всем точкам (не меньше 1). Нужно n ≥ 3 упоминаний; если о месте меньше, берутся заголовки о месте и стране вместе, и это помечено «по стране».
- **Источники.** N = сумма по изданиям лучшего веса d; издание только о стране весит 0,25, все вместе — не больше 2. Var(N) — сумма квадратов весов (пуассоновское приближение). Для события N берётся из числа независимых изданий кластера.
- **Тяжесть.** h = 0,5 · (1 − e^(−k / 1,5)) + 0,5 · max(0, −тон), k — число слов о насилии; тон — словарный тон проекта. ω = d (о месте) или 0,25·d (о стране); h̄ и s² — по всему корпусу.
- **Расстояния** — по большому кругу (R = 6371,0088 км). Внутри полигона зоны d = 0, снаружи — до ближайшей вершины или центра. Интенсивность aⱼ: высокая 1, средняя 0,66, низкая 0,33. К σ добавляется пол 0,02.

## Агрегирование

По измеренным факторам с перенормированными весами w̃ — степенное среднее порядка 2 (сильный фактор не растворяется в слабых):

M = (Σ w̃ᵢ xᵢ²)^½, покрытие = Σ базовых весов измеренных факторов.

Дисперсия (дельта-метод плюс цена пропусков):

v = Σ_измер (∂M/∂xᵢ · σᵢ)² + Σ_пропущ wᵢ² · Var_по точкам(xᵢ), где ∂M/∂xᵢ = w̃ᵢ xᵢ / M.

Эмпирический байес: μ — среднее M по всем оценённым точкам, τ² = max(Var(M) − среднее v, 0,05²).

λ = τ² / (τ² + v), **балл = 100 · (λM + (1 − λ)μ)**, интервал 90% = балл ± 1,6449 · 100 · √(λv), обрезанный до [0, 100].

Разложение аддитивно: баллы фактора = 100 · λ · M · w̃ᵢxᵢ² / Σ w̃x², плюс «априорный уровень» 100 · (1 − λ) · μ. Сумма равна баллу (с точностью округления). Чем меньше данных, тем меньше λ, тем ближе балл к μ и шире интервал.

## Когда оценки нет

- нет ни одного текущего свидетельства (новости, индекс страны, рынок) — одной географии мало;
- измерено меньше 0,25 веса;
- оценено меньше трёх точек (нет априорного уровня).

Пропущенный фактор помечается «нет данных» с причиной и не заменяется нулём или значением по умолчанию.

## Ограничения

- Веса, ширины ядер и полупериод — экспертные, на истории не откалиброваны. Балл — сравнительная оценка внимания и напряжённости, не вероятность события.
- Дисперсии факторов складываются как независимые, хотя новостные факторы связаны: интервал, вероятно, уже настоящего. Неопределённость самих весов в него не входит.
- Сопоставление по ключевым словам ошибается: омонимы, косвенные упоминания, только английские заголовки.
- Точки одной страны без собственных упоминаний получают близкие баллы.
- Зона конфликта по построению имеет близость 1 к самой себе, пролив и объект — близость к самим себе.
- Статичные слои обновляются вручную; расстояние до вершин, а не до рёбер полигона.
- Знаки после запятой отражают расчёт, а не точность: точность показывает интервал.
